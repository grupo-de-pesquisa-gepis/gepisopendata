* 1. Visão Geral e Nova Filosofia de Arquitetura

O aplicativo *Gepis Dados Abertos* necessita de uma separação estrita entre a **Lógica de Negócio / Processamento de Dados (Core)** e o **Framework de Interface Desktop (Tauri v2)**.

Atualmente, funções essenciais como download de microdados do INEP, extração de ZIP, leitura de planilhas Excel (Calamine), persistência em JSON e pipeline Polars estão fortemente acopladas a parâmetros como ~app_handle: tauri::AppHandle~.

** O Princípio Central: Arquitetura Hexagonal (Ports & Adapters)
Toda a lógica de negócios e I/O do Rust deve ser **100% agnóstica ao Tauri**:
- O *Core* opera exclusivamente com tipos padrão do Rust (~std::path::Path~, ~PathBuf~, structs de domínio, streams, closures/traits de progresso).
- O *Tauri* atua apenas como um **Adaptador de Apresentação (Adapter/Controller)**: extrai caminhos do sistema operacional, repassa para o Core e devolve o resultado via IPC.
- *Benefício Imediato*: Qualquer funcionalidade (como baixar microdados do INEP, processar ETL ou manipular JSONs) pode ser executada via **Linha de Comando (CLI)**, scripts automatizados, rotinas de CI/CD ou testes unitários sem abrir nenhuma janela gráfica.

* 2. Módulo de Persistência JSON Dedicado (=fzl-persistence-json=)

Para atender à necessidade de gerenciamento consistente e desacoplado dos arquivos JSON (=datasets-registry.json=, =analyses-history.json=, =github-config.json=), definimos um módulo utilitário genérico de persistência.

** 2.1. O que é o =fzl_persistence_json=?
É uma camada genérica e thread-safe para operações de armazenamento baseadas em arquivos JSON com os seguintes recursos:
- *Escrita Atômica*: Grava primeiro em arquivo temporário (=.tmp=) e renomeia atomicamente, prevenindo corrupção de dados em caso de falha ou desligamento.
- *Tipagem Estrita via Generics*: Opera sobre qualquer tipo que implemente ~serde::Serialize + serde::de::DeserializeOwned~.
- *Multidestino (Dual-Write Dev/Prod)*: Suporta sincronização automática entre múltiplos caminhos (ex: AppData local e diretório do Angular em modo de desenvolvimento).
- *Isenção Total do Tauri*: Opera apenas recebendo ~&Path~ ou ~PathBuf~.

** 2.2. Assinatura da Interface (=services/persistence/json_store.rs=)
#+BEGIN_SRC rust
use std::path::{Path, PathBuf};
use serde::{de::DeserializeOwned, Serialize};

pub struct JsonStore;

impl JsonStore {
    /// Carrega e desserializa um arquivo JSON. Se não existir, retorna um Vec vazio ou Default.
    pub fn load_list<T: DeserializeOwned>(path: &Path) -> Result<Vec<T>, String> { ... }

    pub fn load_optional<T: DeserializeOwned>(path: &Path) -> Result<Option<T>, String> { ... }

    /// Salva de forma atômica e formatada (pretty-print) em um ou múltiplos destinos
    pub fn save_atomic<T: Serialize>(paths: &[PathBuf], data: &T) -> Result<(), String> { ... }

    /// Upsert por ID ou predicado
    pub fn upsert_item<T, F>(paths: &[PathBuf], item: T, matcher: F) -> Result<(), String>
    where
        T: Serialize + DeserializeOwned + Clone,
        F: Fn(&T) -> bool,
    { ... }

    /// Remove itens que satisfaçam um predicado
    pub fn delete_items<T, F>(paths: &[PathBuf], predicate: F) -> Result<usize, String>
    where
        T: Serialize + DeserializeOwned,
        F: Fn(&T) -> bool,
    { ... }
}

*** Adaptador Tauri (=commands/dataset_commands.rs=)
#+BEGIN_SRC rust
use tauri::{AppHandle, Emitter};
use crate::services::{downloader, path_resolver, registry_repo};

#[tauri::command]
pub async fn download_dataset(
    app_handle: AppHandle,
    url: String,
    metadata: serde_json::Value
) -> Result<String, String> {
    // 1. Tauri apenas resolve os caminhos do SO
    let target_dir = path_resolver::get_dataset_target_dir(&app_handle, &metadata)?;
    
    // 2. Chama o Core puro (repassando callback de progresso opcional via Tauri Emitter)
    let app_clone = app_handle.clone();
    let options = downloader::DownloadOptions {
        url: &url,
        target_dir: &target_dir,
        expected_format: metadata["formato"].as_str().unwrap_or("outro"),
        on_progress: Some(Box::new(move |downloaded, total| {
            let _ = app_clone.emit("download-progress", (downloaded, total));
        })),
    };
    let final_files = downloader::execute_download(options).await?;

    // 3. Atualiza registro através do repositório
    registry_repo::register_dataset(&app_handle, metadata, final_files, &target_dir)?;

    Ok(format!("Download concluído com sucesso"))
}
#+END_SRC

* 5. Benefícios da Abordagem

1. *Testabilidade*: Testes unitários para o downloader, o leitor de dicionário Calamine, o agregador Polars e o repositório JSON rodam em milissegundos com ~cargo test~ puro, sem inicializar o webview.
2. *Reutilização*: O módulo =services= pode ser empacotado como uma crate independente no futuro (=gepis-core= / =fzl-persistence-json=) ou consumido por uma CLI de processamento em lote.
3. *Manutenibilidade*: O código do Tauri fica restrito a traduzir requisições de tela em chamadas ao Core. Qualquer mudança na API do Tauri (v2 -> v3) não afeta nenhuma regra de negócio.
4. *Robustez*: O uso de escrita atômica no armazenamento JSON elimina o risco de arquivos corrompidos durante falhas.
