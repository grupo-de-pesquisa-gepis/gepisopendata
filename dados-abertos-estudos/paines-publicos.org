* Objetivo

Este documento reúne os principais portais oficiais de dados abertos e painéis analíticos relacionados à educação brasileira.

É destinado a:

- Pesquisadores
- Analistas de Dados
- Gestores Públicos
- Profissionais de BI
- Especialistas em Geoprocessamento
- Usuários de QGIS, PostgreSQL/PostGIS, Power BI e Python

* 1. INEP - Dados Abertos

Portal principal de dados educacionais do Brasil.

Disponibiliza:

- Indicadores Educacionais
- Microdados
- Sinopses Estatísticas
- Inep Data
- Bases do Censo Escolar
- Bases do Enem
- Bases do Enade
- Bases do Saeb
- Bases da Educação Superior

Site:

https://www.gov.br/inep/pt-br/acesso-a-informacao/dados-abertos

Fonte:
https://www.gov.br/inep/pt-br/acesso-a-informacao/dados-abertos

* Recomendação para Georreferenciamento

Para construir uma infraestrutura nacional de dados educacionais geográficos, recomenda-se integrar:

1. Microdados do Censo Escolar (INEP)
2. Painéis do INEP
3. Bases do IBGE
4. Bases do FNDE
5. Dados.gov.br
6. Dados do MEC
7. Dados da CAPES

Ferramentas recomendadas:

- PostgreSQL
- PostGIS
- QGIS
- Python
- Power BI
- DuckDB

* Observação Final

O conjunto INEP + IBGE + FNDE constitui atualmente a combinação mais importante para análises territoriais da educação brasileira, permitindo estudos sobre:

- Localização de escolas
- Matrículas
- Docentes
- Infraestrutura
- Transporte escolar
- Investimentos públicos
- Desempenho educacional
- Indicadores socioeconômicos
